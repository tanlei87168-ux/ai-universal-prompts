# AI 万能提示词 · AI Universal Prompts

> 一个面向普通人、职场人士、开发者、创作者和创业者的中文 AI Prompt 开源库。
>
> **不知道怎么问 AI？来这里复制一个就行。**

本项目收集、整理并持续优化可直接复制使用的高质量中文提示词，覆盖办公、写作、编程开发、AI 绘画、AI 视频、自媒体、电商、销售客服、商业分析、教育学习、法律、生活与 AI 智能体等常见场景。

适用于 ChatGPT、Claude、Gemini、DeepSeek、豆包、Kimi、通义千问，以及 Cursor、Codex、Claude Code、GitHub Copilot 等 AI 开发工具。不同模型和版本能力存在差异，建议根据真实任务提供代码、数据、截图、日志和验收标准。

## ✨ 项目特点

- **中文优先**：尽量用自然、清晰的中文表达，不要求用户懂 Prompt Engineering。
- **复制即用**：每条提示词尽量做到拿来就能用，只需要替换少量变量。
- **真实场景**：按真实任务分类，不做纯概念堆砌。
- **工程化开发**：开发类提示词覆盖需求、架构、页面、组件、API、数据库、测试、Debug、Review、部署完整链路。
- **高频组件**：文件上传、搜索选择器、树形选择器、日期范围、分页、步骤表单、文件预览、图表、富文本、消息中心、WebSocket、拖拽排序等均有专用 Prompt。
- **可组合**：提供“万能母提示词”，可继续生成行业和任务专用提示词。
- **持续优化**：欢迎提交更好的版本、真实案例和模型适配建议。
- **开源共建**：适合个人学习、团队内部使用，也欢迎二次开发。

## 🧩 通用变量写法

本仓库常用以下占位符：

```text
{{任务目标}}
{{背景信息}}
{{目标用户}}
{{输入内容}}
{{限制条件}}
{{输出格式}}
{{参考示例}}
```

使用时把 `{{...}}` 替换成你自己的内容即可。若暂时没有某项信息，可以保留为空，让模型先判断是否需要补充。

## 🧠 推荐的通用提示词结构

一条稳定的 Prompt 通常包含：

```text
角色（Role）
背景（Context）
目标（Goal）
输入（Input）
任务步骤（Workflow）
约束（Constraints）
输出格式（Output Format）
质量检查（Quality Check）
```

不是所有任务都必须写满八项。简单任务保持简单，复杂任务再增加约束和检查标准。

## ✅ 使用建议

1. **先给目标，再给材料**：告诉 AI 最终要得到什么。
2. **提供真实上下文**：行业、受众、平台、产品、代码、接口、错误日志和限制条件越明确，结果通常越好。
3. **明确输出格式**：例如表格、Markdown、JSON、脚本、代码、补丁或分步骤方案。
4. **重要任务要求自检**：让模型检查遗漏、矛盾、事实不确定性和边界条件。
5. **开发任务先读后改**：让 AI 先理解仓库、调用链和已有规范，再实施修改。
6. **不要迷信“越长越好”**：Prompt 的目标是减少歧义，不是堆字数。

## ⚠️ 重要说明

- AI 可能生成错误、过时或虚构信息，请对重要内容进行人工核验。
- AI 生成代码在合并和上线前应经过测试、Review 和安全检查。
- 医疗、法律、金融、安全等高风险场景，提示词只能辅助整理信息，不能替代专业人士的判断。
- 涉及隐私、商业机密、账号密钥等敏感信息时，请先脱敏再提交给第三方模型。
- 本仓库不保证某一提示词在所有模型、所有版本中产生完全一致的输出。
