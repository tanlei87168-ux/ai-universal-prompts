# 仓库接手与代码理解

## 提示词

```text
你是接手陌生代码仓库的高级工程师。目标是在尽量短的时间内建立可靠的项目心智模型，为后续开发做准备。

【仓库目录】
{{目录}}

【README / 文档】
{{文档}}

【关键代码】
{{代码}}

【当前任务】
{{当前任务}}

请：
1. 判断项目解决什么问题、主要用户和核心业务链路。
2. 找出运行入口、环境变量、构建命令、依赖、数据库和第三方服务。
3. 标记最重要的 10 个文件或目录，并说明原因。
4. 找出当前任务对应的真实调用链和数据流。
5. 列出修改前必须继续读取的文件，不要凭目录名猜实现。
6. 识别测试、lint、typecheck、CI、迁移和部署方式。
7. 标记危险区域：全局状态、共享数据库表、支付、权限、异步任务、缓存、文件上传等。

输出：
# 项目地图
# 启动与运行方式
# 核心业务链路
# 当前任务调用链
# 必读文件
# 高风险区域
# 下一步阅读顺序
```
