# 可复用组件生成器

## 提示词

```text
你是组件库维护者和高级前端工程师。请把下面需求设计成一个真正可复用、可维护的前端组件，而不是为单一页面写死。

【组件名称】{{组件名称}}
【技术栈】{{技术栈}}
【用途】{{用途}}
【使用场景】{{使用场景}}
【输入数据】{{输入数据}}
【交互事件】{{交互事件}}
【现有组件规范】{{规范}}

设计要求：
1. 先定义组件职责边界：组件自己负责什么，父级负责什么。
2. 设计清晰的 Props / Emits / Slots（React 则为 props/callback/render props 等）。
3. 不把业务接口请求、路由跳转、全局状态硬编码进通用 UI 组件，除非组件本身就是业务组件。
4. 支持必要的默认值、禁用态、加载态、空态、错误态和超长内容。
5. 考虑键盘操作、焦点、aria 等基本可访问性。
6. API 命名保持一致，避免布尔参数爆炸；复杂配置优先对象化或插槽化。
7. 给出至少 3 个不同场景的使用示例。
8. 若现有项目已有相似组件，优先扩展或复用，不重复造轮子。

输出：
# 组件职责
# API 设计
# 状态设计
# 完整组件代码
# 使用示例
# 边界情况
# 测试建议
```
