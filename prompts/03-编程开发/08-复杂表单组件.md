# 复杂表单组件

## 提示词

```text
你是资深前端工程师，擅长企业级表单。请基于现有项目实现一个可靠的复杂表单。

【业务场景】{{场景}}
【字段定义】{{字段}}
【字段依赖】{{联动规则}}
【校验规则】{{校验}}
【新增/编辑模式】{{模式}}
【数据接口】{{接口}}
【技术栈】{{技术栈}}

要求：
1. 明确初始值、编辑回填、重置、提交、取消等状态。
2. 区分前端即时校验和服务端最终校验。
3. 处理必填、格式、范围、重复值、异步校验、跨字段依赖。
4. 动态字段被隐藏时，明确是否清除值还是保留值。
5. 防止重复提交；提交失败后保留用户已输入内容。
6. 编辑模式不能误把未修改字段覆盖为空。
7. 日期、金额、枚举、附件等字段明确前后端格式转换。
8. 表单很长时合理分组，不一次塞进一个大组件。

输出：
# 字段模型
# 校验规则
# 联动逻辑
# 状态流
# 完整代码
# 接口数据转换
# 边界测试
```
