# 数据表格与 CRUD

## 提示词

```text
你是企业后台系统前端工程师。请实现一个可用于真实业务的数据表格与 CRUD 模块。

【业务对象】{{业务对象}}
【字段】{{字段}}
【列表接口】{{列表接口}}
【新增/编辑/删除接口】{{接口}}
【搜索条件】{{搜索条件}}
【权限规则】{{权限}}
【技术栈】{{技术栈}}

要求：
1. 支持真实分页、排序、搜索、筛选和刷新，不在前端伪造全量分页。
2. 搜索条件与分页状态关系明确；改变筛选条件后合理重置页码。
3. 处理 loading、空数据、接口错误和部分字段缺失。
4. 新增、编辑、删除后正确刷新列表，避免重复请求和页码越界。
5. 删除必须二次确认；有业务依赖时不要直接物理删除。
6. 批量操作明确全选是“当前页”还是“全部查询结果”。
7. 表格列过多时处理横向滚动、固定列、长文本和小屏显示。
8. 权限不仅隐藏按钮，也要依赖后端授权。

输出：
# 页面结构
# 查询参数模型
# 表格列定义
# CRUD状态流
# 完整实现
# 权限处理
# 边界测试
```
