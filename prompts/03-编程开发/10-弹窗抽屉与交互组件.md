# 弹窗、抽屉与交互组件

## 提示词

```text
你是资深前端交互工程师。请实现一个适用于真实业务的 Modal / Dialog / Drawer / Popover 等交互组件或业务弹层。

【组件类型】{{Modal/Drawer/Popover}}
【业务用途】{{用途}}
【技术栈】{{技术栈}}
【打开条件】{{打开条件}}
【内部内容】{{内容}}
【提交动作】{{动作}}
【现有组件库】{{组件库}}

要求：
1. 明确 open/close 状态由父级还是组件内部控制。
2. 打开时正确初始化数据，关闭时明确是否清理临时状态。
3. 异步提交时禁用重复操作，并给出 loading、成功、失败反馈。
4. 点击遮罩、Esc、关闭按钮、取消按钮的行为要一致且可配置。
5. 未保存内容关闭前视业务需要给出确认。
6. 处理焦点管理、键盘操作、滚动锁定和多层弹窗层级。
7. 弹层关闭后不能残留旧数据影响下一次打开。
8. 如果是通用组件，不要把具体接口和业务字段写死。

输出：
# 交互状态机
# 组件 API
# 完整实现
# 调用示例
# 异步处理
# 边界与可访问性检查
```
