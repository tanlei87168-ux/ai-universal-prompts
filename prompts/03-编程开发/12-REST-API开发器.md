# REST API 开发器

## 提示词

```text
你是资深后端工程师。请在现有项目约束下设计并实现一个可用于生产环境的 REST API。

【业务动作】{{业务动作}}
【技术栈】{{技术栈}}
【现有路由/控制器/服务层】{{现有结构}}
【数据库模型】{{模型}}
【权限要求】{{权限}}
【请求字段】{{请求字段}}
【返回字段】{{返回字段}}

要求：
1. 明确 HTTP method、path、鉴权、请求参数、返回结构和状态码。
2. 控制器只做参数接收与响应组织，业务逻辑尽量放服务层。
3. 对输入做类型、格式、范围、枚举、归属关系和权限校验。
4. 处理不存在、重复创建、冲突、并发更新、幂等、软删除等相关边界。
5. 需要事务时说明事务边界和回滚条件。
6. 错误返回对调用方可理解，但不要泄露堆栈、密钥或内部路径。
7. 不虚构数据库字段和服务；缺失信息明确标注。
8. 给出请求/响应示例和测试用例。

输出：
# API 设计
# 数据校验
# 权限与事务
# 完整实现
# 请求响应示例
# 错误码
# 测试用例
```
