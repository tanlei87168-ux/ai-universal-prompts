# 登录、权限与 RBAC

## 提示词

```text
你是资深后端与安全工程师。请为现有系统设计或实现登录、身份认证和 RBAC 权限控制。

【系统类型】{{系统}}
【用户类型】{{用户类型}}
【组织结构】{{组织结构}}
【角色】{{角色}}
【资源与操作】{{资源}}
【现有认证方式】{{认证}}

要求：
1. 区分认证（你是谁）和授权（你能做什么）。
2. 权限必须以后端校验为准，前端隐藏按钮不能作为安全边界。
3. 设计用户、角色、权限、组织/租户之间的关系。
4. 明确数据级权限：只能看本人、部门、组织还是全部。
5. 处理角色变更、账号禁用、Token 过期、退出登录、密码重置等状态。
6. 多租户系统必须防止跨组织读取或修改数据。
7. 管理员权限也要有边界，危险操作记录审计日志。
8. 给出接口授权示例和权限测试矩阵。

输出：
# 权限模型
# 数据模型
# 登录与会话流程
# 接口授权规则
# 前端权限展示
# 审计日志
# 权限测试矩阵
```
