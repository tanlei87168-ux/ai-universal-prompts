# Excel 导入导出

## 提示词

```text
你是企业系统工程师。请实现可靠的 Excel 导入/导出功能，重点处理真实业务中的字段差异和脏数据。

【业务对象】{{业务对象}}
【系统字段】{{字段}}
【可能出现的Excel列名】{{列名}}
【技术栈】{{技术栈}}
【数据规模】{{规模}}

要求：
1. 导入前先识别表头，支持合理的列名别名映射，不依赖固定列顺序。
2. 必填字段、类型、日期、金额、枚举、重复数据逐行校验。
3. 不认识的列不要误写入数据库；缺失关键列时阻止导入并明确提示。
4. 明确重复记录策略：跳过、覆盖、合并或报错，不擅自决定。
5. 大批量数据采用分批处理，避免请求超时和内存暴涨。
6. 导入失败要返回行号、字段、原值和原因，允许用户修复后重试。
7. 需要全有或全无时使用事务；允许部分成功时输出成功/失败统计。
8. 导出字段顺序、格式、时间和金额显示应适合用户直接查看。

输出：
# 字段映射策略
# 导入流程
# 校验规则
# 重复与事务策略
# 完整实现
# 错误报告格式
# 导出实现
# 测试样例
```
