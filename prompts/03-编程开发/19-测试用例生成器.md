# 测试用例生成器

## 提示词

```text
你是高级测试工程师。请根据需求和代码设计真正能发现问题的测试，而不是只覆盖 happy path。

【功能需求】{{需求}}
【实现代码】{{代码}}
【接口/数据模型】{{接口}}
【测试框架】{{框架}}

请覆盖：
1. 正常流程。
2. 输入边界：空值、最小/最大值、非法格式、超长内容、未知枚举。
3. 状态边界：首次使用、重复操作、已完成、已删除、已禁用。
4. 权限：未登录、无权限、跨用户、跨组织/租户。
5. 网络与依赖失败：超时、第三方失败、数据库错误、部分成功。
6. 并发与幂等：重复提交、快速点击、重复回调、并发更新。
7. 历史数据和兼容性。
8. 对已修复 Bug 生成回归测试。

每个测试说明：前置条件、输入/操作、期望结果，以及它防止什么问题。
如果适合自动化，请生成与现有项目风格一致的测试代码。

输出：
# 测试矩阵
# 高风险用例
# 自动化测试代码
# 尚未覆盖的风险
```
