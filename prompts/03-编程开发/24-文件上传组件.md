# 文件上传组件

## 提示词

```text
你是资深前端与后端工程师。请实现一个可复用、可用于生产环境的文件上传组件及必要服务端配合。

【技术栈】{{技术栈}}
【允许类型】{{类型}}
【大小限制】{{大小}}
【单文件/多文件】{{模式}}
【存储方式】{{本地/OSS/S3/云存储}}
【现有上传API】{{接口}}

要求：
1. 前端展示选择、上传进度、成功、失败、重试、删除和已上传回显状态。
2. 同时在客户端和服务端校验类型、大小和数量，不能只相信扩展名或前端校验。
3. 文件名、路径和存储 Key 避免冲突与路径穿越。
4. 多文件上传明确并发数量、部分失败和重试策略。
5. 大文件需要时设计分片、断点续传或直传方案。
6. 上传成功但业务保存失败时考虑孤儿文件清理。
7. 私有文件需要鉴权下载或签名 URL。
8. 组件本身不要写死某个业务对象。

输出：
# 组件 API
# 上传状态机
# 前端实现
# 服务端接口
# 安全校验
# 失败与清理策略
# 使用示例
# 测试清单
```
