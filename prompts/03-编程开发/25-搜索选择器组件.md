# 搜索选择器组件

## 提示词

```text
你是资深前端工程师。请实现一个支持远程搜索、模糊匹配和大数据量的选择器组件。

【选择对象】{{用户/商品/库存品类/客户/其他}}
【技术栈】{{技术栈}}
【搜索接口】{{接口}}
【显示字段】{{显示字段}}
【返回值】{{value字段}}
【单选/多选】{{模式}}

要求：
1. 支持关键词模糊搜索，不要求用户输入完全匹配名称。
2. 输入防抖，取消或忽略过期请求，避免旧结果覆盖新结果。
3. 明确初始回显：只有 ID 时也能正确显示名称。
4. 处理空关键词默认列表、无结果、加载失败、分页/滚动加载。
5. 同名对象要显示足够的辅助信息用于区分。
6. 多选时处理去重、已选项保留、最大数量和删除。
7. 不把全量数据一次性加载到前端后假装远程搜索。
8. 输出值类型与表单模型保持稳定。

输出：
# 组件 API
# 搜索与回显流程
# 完整代码
# 接口约定
# 大数据量处理
# 边界测试
```
