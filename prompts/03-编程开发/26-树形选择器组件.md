# 树形选择器组件

## 提示词

```text
你是资深前端工程师。请实现适用于部门、分类、地区、目录等层级数据的树形选择组件。

【数据类型】{{部门/分类/地区/目录}}
【技术栈】{{技术栈}}
【数据结构】{{结构}}
【单选/多选】{{模式}}
【是否懒加载】{{是/否}}
【权限限制】{{权限}}

要求：
1. 明确 id、parentId、children、label 等字段映射。
2. 支持展开/折叠、搜索定位、默认选中和编辑回显。
3. 大树支持懒加载或虚拟化，避免一次渲染全部节点。
4. 多选模式明确父子节点联动规则：严格模式或级联模式。
5. 已禁用/无权限节点不能通过前端技巧绕过选择限制。
6. 处理循环引用、孤儿节点、重复 id 和缺失父节点等异常数据。
7. 选中结果应保持稳定的数据格式，不能随 UI 库内部对象变化。

输出：
# 数据模型
# 组件 API
# 父子联动规则
# 完整实现
# 搜索与懒加载
# 异常数据处理
# 测试清单
```
