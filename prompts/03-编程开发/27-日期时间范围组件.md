# 日期时间范围组件

## 提示词

```text
你是资深前端工程师。请实现可靠的日期、时间或日期范围选择组件，并正确处理前后端时间语义。

【业务场景】{{场景}}
【技术栈】{{技术栈}}
【选择类型】{{日期/日期时间/范围}}
【时区】{{时区}}
【接口格式】{{ISO/时间戳/字符串}}
【限制规则】{{最早/最晚/不可选日期}}

要求：
1. 明确 UI 展示时间、浏览器本地时间、服务器时间和数据库时间的转换关系。
2. 不混用秒级和毫秒级时间戳。
3. 范围选择保证开始时间不晚于结束时间，并处理同一天边界。
4. 需要整日统计时说明开始/结束边界是否包含。
5. 处理清空、编辑回显、默认值、跨月/跨年和夏令时影响（如适用）。
6. 禁用日期规则应由明确业务逻辑驱动。
7. 给出接口提交前和返回后的转换函数。

输出：
# 时间语义
# 组件 API
# 完整实现
# 格式转换
# 边界规则
# 测试样例
```
