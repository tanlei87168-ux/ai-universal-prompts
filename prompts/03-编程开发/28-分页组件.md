# 分页组件

## 提示词

```text
你是资深前端工程师。请实现一个可复用分页组件，并确保与真实服务端分页模型正确协作。

【技术栈】{{技术栈}}
【分页模型】{{page/pageSize 或 cursor}}
【总数】{{是否提供total}}
【页面大小选项】{{选项}}
【URL是否同步】{{是/否}}

要求：
1. 明确页码从 0 还是 1 开始，前后端转换只能在一个边界处理。
2. 搜索/筛选条件变化后正确重置页码。
3. 删除当前页最后一条记录后避免停留在不存在的页。
4. 改变 pageSize 后重新计算合理页码。
5. 请求中的旧分页结果不能覆盖较新的查询结果。
6. cursor 分页不要伪装成 total 页码分页。
7. 如果状态同步到 URL，刷新、返回、分享链接后应恢复相同查询状态。

输出：
# 分页模型
# 组件 API
# 与列表请求的状态流
# 完整实现
# URL同步（如适用）
# 边界测试
```
