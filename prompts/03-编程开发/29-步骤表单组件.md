# 步骤表单组件

## 提示词

```text
你是资深前端工程师。请实现多步骤表单 / Wizard，适用于开户、配置向导、复杂录入等流程。

【业务流程】{{流程}}
【步骤】{{步骤}}
【每步字段】{{字段}}
【是否允许返回修改】{{是/否}}
【保存方式】{{一次提交/分步保存}}
【技术栈】{{技术栈}}

要求：
1. 明确当前步骤、已完成步骤、可访问步骤和跳转规则。
2. 下一步前只校验当前步骤必要字段，最终提交再做全量校验。
3. 返回上一步不能丢失已填写数据。
4. 分步保存时明确草稿状态、恢复逻辑和最终提交状态。
5. 防止用户通过直接修改 URL/步骤索引跳过必须步骤。
6. 最终提交处理 loading、重复提交、失败重试和部分保存问题。
7. 刷新页面是否保留进度需按业务说明实现。

输出：
# 步骤状态机
# 数据模型
# 组件结构
# 完整实现
# 保存与恢复策略
# 边界测试
```
