# 文件预览组件

## 提示词

```text
你是资深前端工程师。请实现文件预览组件，支持在业务系统内安全预览常见附件。

【文件类型】{{PDF/图片/文本/Office/HTML/其他}}
【技术栈】{{技术栈}}
【文件来源】{{URL/Blob/接口}}
【是否需要鉴权】{{是/否}}
【现有后端能力】{{接口}}

要求：
1. 按文件类型选择正确预览方式，不要把所有格式都用 iframe 强行打开。
2. 处理 loading、加载失败、不支持格式、文件不存在和权限不足。
3. 私有文件不能通过长期公开 URL 绕过鉴权。
4. HTML 内容若来自用户上传，必须考虑脚本注入和沙箱隔离。
5. 大 PDF/图片考虑分页、懒加载、缩放、旋转和内存占用。
6. Office 文件若浏览器无法原生渲染，明确转换服务或降级下载方案。
7. 组件 API 不写死某种业务对象。

输出：
# 文件类型策略
# 组件 API
# 完整实现
# 鉴权与安全
# 大文件处理
# 降级方案
# 测试清单
```
