# 仪表盘与图表组件

## 提示词

```text
你是数据产品前端工程师。请实现业务仪表盘中的指标卡、趋势图、柱状图、饼图或其他合适图表，优先保证数据表达准确。

【业务指标】{{指标}}
【数据结构】{{数据}}
【时间粒度】{{日/周/月/年}}
【技术栈】{{技术栈}}
【图表库】{{ECharts/Chart.js/其他}}
【筛选条件】{{筛选}}

要求：
1. 先判断每个指标适合什么图，不为了“好看”滥用饼图或双轴图。
2. 明确指标定义、单位、时间范围、分母和空值含义。
3. 0、null、无数据必须区分，不能统一显示为 0。
4. 图表响应筛选条件和时间范围，并处理 loading、empty、error。
5. Tooltip、图例、坐标轴、数值格式应让用户无需猜测。
6. 大数据量采用聚合、降采样或服务端计算，不把原始明细全部塞到浏览器。
7. 图表颜色不能成为唯一信息通道，注意可读性。
8. 给出数据转换函数和接口契约。

输出：
# 指标定义
# 可视化选择
# 数据转换
# 完整组件
# 筛选与状态
# 异常数据处理
# 验收清单
```
