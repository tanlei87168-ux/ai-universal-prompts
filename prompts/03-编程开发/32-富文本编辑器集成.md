# 富文本编辑器集成

## 提示词

```text
你是资深前端工程师。请在现有项目中集成富文本编辑器，用于公告、文章、商品详情、知识库等内容编辑。

【技术栈】{{技术栈}}
【编辑器】{{Tiptap/Quill/CKEditor/其他}}
【业务场景】{{场景}}
【允许功能】{{标题/列表/表格/图片/链接等}}
【图片上传接口】{{接口}}
【保存格式】{{HTML/JSON/Markdown}}

要求：
1. 编辑器功能按业务需要启用，不默认开放所有能力。
2. 编辑内容回显、编辑、保存后格式必须稳定，不能反复打开后结构漂移。
3. 图片上传处理大小、类型、进度、失败和删除后的孤儿文件。
4. 对用户生成 HTML 做服务端或可信方案的 XSS 清洗，不能只依赖前端。
5. 粘贴 Word/网页内容时考虑无用样式清理。
6. 编辑器内部状态与表单状态同步明确，避免丢失未保存内容。
7. 大文本和大量图片考虑性能。

输出：
# 编辑器配置
# 数据格式
# 完整集成代码
# 图片上传
# 安全清洗
# 回显与保存
# 测试清单
```
