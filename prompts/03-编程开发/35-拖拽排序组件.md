# 拖拽排序组件

## 提示词

```text
你是资深前端与后端工程师。请实现可用于列表、菜单、看板、图片等场景的拖拽排序功能。

【业务对象】{{对象}}
【技术栈】{{技术栈}}
【排序范围】{{同组/跨组}}
【现有字段】{{sort/order/index}}
【数据规模】{{规模}}

要求：
1. 明确拖拽前、拖拽中、放置成功和保存失败的状态。
2. UI 应提供清晰拖拽手柄、目标位置反馈和不可拖拽状态。
3. 排序持久化不能每次都无脑重写所有记录；根据规模选择连续序号、间隔值或 rank 算法。
4. 跨组拖动时同时处理 groupId 和排序位置。
5. 服务端必须校验用户是否有权移动这些对象。
6. 保存失败时恢复原顺序或明确提示，不能让界面与数据库静默不一致。
7. 并发排序时考虑版本冲突或最终一致性策略。
8. 兼顾键盘操作或提供非拖拽的替代排序方式（如适用）。

输出：
# 数据排序模型
# 组件 API
# 前端实现
# 后端持久化
# 失败回滚
# 并发处理
# 测试清单
```
