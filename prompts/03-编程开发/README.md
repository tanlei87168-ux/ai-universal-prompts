# 编程开发提示词

这一目录面向使用 ChatGPT、Claude、Codex、Cursor、GitHub Copilot 等 AI 辅助开发工具的开发者和产品人员。

目标不是让 AI “随便写一段代码”，而是让它按真实软件工程流程工作：先理解现有系统，再实施最小改动，最后验证结果。
