# 编程开发提示词

这一目录面向使用 ChatGPT、Claude、Codex、Cursor、Claude Code、GitHub Copilot 等 AI 辅助开发工具的开发者和产品人员。

目标不是让 AI “随便写一段代码”，而是让它按真实软件工程流程工作：**先理解现有系统，再实施最小改动，最后验证结果。**

目前已覆盖 **35 个开发场景**，从需求分析、仓库理解、页面和组件开发，到 API、数据库、权限、测试、安全、性能和上线。

## 推荐工作流

```text
需求 → 02 需求转开发方案
     → 03/04 理解架构与仓库
     → 05~16 实施页面、组件、API、数据库
     → 17 Bug诊断
     → 18 Code Review
     → 19 测试
     → 20 安全审查
     → 21 性能优化（需要时）
     → 23 上线检查
```

> 建议把仓库结构、相关代码、接口文档、数据库结构、截图、报错日志和验收标准一起提供给 AI。不要让 AI 在没有读取真实上下文的情况下猜测项目结构。
