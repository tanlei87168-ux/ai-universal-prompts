# 宋韵国风商业海报

适用于商场活动、文旅宣传、节庆营销、品牌活动、茶饮餐饮、新中式空间等场景。

核心风格：**新中式国风 + 宋韵雅集 + 工笔淡彩 + 水墨留白 + 商业海报排版**。

```text

【主标题】{{主标题}}
【副标题】{{副标题}}

【比例】{{比例，默认3:4}}
【核心人物/场景】{{人物与场景}}
【必须出现元素】{{元素}}
【品牌或项目色】{{品牌色，可留空}}

画面采用工笔人物结合淡彩水墨插画表现，具有宣纸肌理和古典留白。主体为古代雅集场景，多位身着宋制或新中式汉服的人物在园林湖畔饮茶、赏景、闲谈，周围点缀亭台楼阁、石桥、宫灯、竹影、枫叶、远山、湖水与云纹。

整体配色低饱和，以米白、青灰、黛青、浅绛、朱砂红为主，气质清雅、精致、细腻、高级。构图为竖版商业海报，顶部保留书法主标题区域，中部为精美主视觉插画，底部保留活动文案区域，并加入印章、宋体小字、中式装饰纹样。

要求：
1. 画面必须有明显东方美学气质，不做欧美卡通风。
2. 人物姿态自然、比例准确，避免手指和肢体错误。
3. 主体层次清晰，前景、中景、远景完整。
4. 留白要充足，不能把所有区域填满。
5. 不使用高饱和霓虹色，不做赛博朋克。
6. 如模型中文文字能力不稳定，优先生成无字或只保留排版留白区域，中文标题后期排版。
7. 整体达到高端商业活动主视觉、品牌海报、文旅宣传物料的完成度。
```

## 十、使用建议

1. **做海报**：使用“万能母提示词”或“商场活动主视觉版本”。
2. **只出底图**：使用“纯插画版本”，后期再排标题与活动信息。
3. **换主题**：保留宋韵、工笔淡彩、低饱和、留白等风格词，只替换人物、场景和活动主题。
4. **做文旅**：把园林替换为真实城市地标、非遗、文物、山水景观。
5. **做品牌活动**：把品牌主色作为点缀色，不要破坏整体低饱和东方审美。
6. **做系列图**：固定人物画法、配色、宣纸纹理和排版骨架，只替换季节、场景和活动内容。
