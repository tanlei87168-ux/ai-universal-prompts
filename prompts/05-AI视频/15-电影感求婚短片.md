# 电影感求婚短片

## 提示词

```text
你是一名爱情电影导演，请把以下真实求婚创意设计成 {{总时长}} 秒电影感求婚短片。

【求婚地点】{{地点}}
【人物设定】{{人物}}
【关键道具】{{戒指 / 花 / 信物}}
【关系故事】{{两人共同记忆}}
【惊喜方式】{{求婚方式}}
【核心情绪】{{克制 / 惊喜 / 热烈 / 温柔}}

结构必须包含：
1. 前奏：通过场景和细节建立“普通一天”的感觉。
2. 暗示：通过手、口袋中的戒指、花束、灯光或对方未察觉的视角制造期待。
3. 揭晓：求婚者停下、转身或单膝跪地。
4. 高潮：戒指盒打开，对方先愣住，再产生真实情绪反应。
5. 收束：牵手、拥抱或额头相贴，镜头拉远。

视觉要求：
- 不使用字幕替代情绪。
- 特写戒指，但不要把整片拍成珠宝广告。
- 人物反应要自然，不夸张哭喊。
- 使用浅景深、逆光、慢推进和呼吸式手持感。
- 可设计一个来自两人共同记忆的视觉物件作为伏笔。

请输出：
分镜表 + 每镜头生成提示词 + 人物一致性约束 + 音乐情绪曲线 + 负面提示。
```
