# 婚纱旅拍短片

## 提示词

```text
生成一支 {{总时长}} 秒电影感婚纱旅拍短片。

【地点】{{城市 / 海边 / 草原 / 雪山 / 古城}}
【新人】{{人物设定}}
【服装】{{婚纱和礼服}}
【季节与天气】{{天气}}
【风格】{{高级纪实 / 浪漫电影 / 公路感 / 东方诗意}}

不要把视频做成连续摆拍照片，而要建立“二人在旅途中相爱”的运动感。

镜头必须覆盖：
- 大环境建立镜头；
- 两人并肩前行；
- 新娘回头或裙摆被风吹起；
- 新郎自然整理头纱或牵手；
- 奔跑、转身、相视而笑等轻动作；
- 手部、戒指、衣料、花束细节；
- 当地独有地貌或城市元素；
- 黄昏或夜色中的结束镜头。

节奏：
前段轻快，中段情绪展开，最后安静收束。

要求：
真实自然、不过度摆拍；地点特色必须明显；人物服装和五官保持稳定；天气和光线在连续镜头中保持逻辑一致。

输出：
旅行叙事主线、时间轴分镜、逐镜提示词、转场设计、人物一致性说明、负面约束。
```
