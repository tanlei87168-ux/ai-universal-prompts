# 婚礼开场先导片

## 提示词

```text
你是一名婚礼电影预告片导演，请生成一支 {{总时长}} 秒婚礼开场先导片。

目标：
适合婚礼现场正式仪式开始前播放，让宾客在短时间内进入情绪。

【新人故事】{{相识、相恋、重要节点}}
【婚礼主题】{{主题}}
【主视觉】{{花材 / 色彩 / 场地}}
【视频风格】{{史诗 / 高级 / 温柔 / 梦幻 / 东方}}

结构：
0–20%：神秘开场，只展示环境、信物和人物局部。
20–55%：快速建立二人的共同旅程，可用象征化场景而非流水账。
55–80%：节奏和音乐明显增强，人物逐渐完整出现。
80–95%：新人走向彼此或走向婚礼场地。
最后 5%：停在即将相遇、牵手或开启婚礼仪式前的瞬间，为现场登场留出情绪接口。

要求：
- 像电影预告片，不像婚庆 PPT。
- 不依赖文字说明故事。
- 用重复视觉母题建立统一性。
- 音乐必须有明确 build-up。
- 最后不要完全“讲完”，要把高潮留给真实婚礼现场。

请输出：
完整创意概念、时间轴、镜头、音乐节拍、逐镜 AI 视频提示词、舞台播放衔接建议。
```
