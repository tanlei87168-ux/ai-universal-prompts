# AI 视频模型适配改写器

## 适用场景

当你已经有完整的视频创意，但需要把提示词改写成更适合具体视频模型的版本时使用。

## 提示词

```text
你是 AI 视频提示词适配专家。

我要使用的模型：
{{即梦 / 可灵 / Runway / Pika / Veo / Sora / 其他}}

原始视频创意：
{{原始提示词}}

已知模型限制：
{{单次最大时长、是否支持首尾帧、是否支持参考图、镜头控制方式等}}

请不要改变核心创意，只做模型适配。

执行：
1. 从原始创意提取人物、场景、动作、镜头、光线、材质、风格和转场。
2. 判断哪些内容应该放在一个生成片段，哪些必须拆成多个片段。
3. 删除模型难以同时执行的过量动作。
4. 把抽象审美词改成可观察的视觉描述。
5. 如果支持参考图，给出“人物参考图 / 场景参考图 / 首帧 / 尾帧”的使用建议。
6. 如果模型不适合复杂转场，把转场拆为两个可生成镜头并注明剪辑连接方式。
7. 不编造你不确定的模型参数；不确定时标记“需按当前版本确认”。

输出：
# 模型适配后的总方案
# 生成片段拆分
# 每个片段的最终提示词
# 建议参考图
# 后期剪辑连接方式
# 可能失败的点及降级方案
```
