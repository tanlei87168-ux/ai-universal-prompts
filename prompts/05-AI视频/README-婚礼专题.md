## 推荐使用方式

如果只有一句创意，先使用 **AI 婚礼短视频总控提示词** 生成整体方案，再使用 **婚礼分镜脚本生成器** 拆成逐镜头内容。

如果已经有完整创意，但准备在具体模型中生成，最后使用 **AI 视频模型适配改写器**，根据单镜头时长、参考图能力、首尾帧能力等拆分成真正可生成的片段。

## 一致性原则

婚礼 AI 视频特别容易出现人物换脸、服装突变、场景时间跳变和肢体异常。建议每个项目固定以下信息：

```text
人物面部特征
年龄感
发型
体型
新郎服装
新娘服装
戒指 / 捧花等关键道具
婚礼主色
时间与天气
镜头质感
```

多时代故事允许服装和妆造变化，但人物的核心面部特征与气质应保持一致。
