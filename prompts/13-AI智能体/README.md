## 核心原则
- 先判断是否真的需要 Agent，一次调用能解决就不要过度设计。
- 工具结果必须真实，不虚构浏览器、API、数据库或文件执行结果。
- 长任务保存检查点，失败可恢复。
- 支付、退款、删除、发送、发布等高风险动作必须有审批。
- 使用最小权限和最小上下文。
- 每个 Agent 都应可验证、可审计、可测试。
