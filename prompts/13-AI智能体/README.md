# AI 智能体 Prompt 专区

这一目录用于设计和构建可执行的 AI Agent，而不只是普通聊天提示词。

核心原则：

- **先判断是否真的需要 Agent**：一次模型调用或固定工作流能完成，就不要增加不必要复杂度。
- **工具结果必须真实**：不能虚构浏览器、API、数据库、文件或外部系统执行结果。
- **状态可恢复**：长任务必须保存关键检查点，失败后可以从正确位置继续。
- **高风险动作需审批**：支付、退款、删除、发送、发布、合同、权限变更等动作应有人机审批。
- **最小权限**：Agent 只拥有完成任务所需的最小工具和数据访问范围。
- **可验证**：每个 Agent 都应有明确成功标准、测试集和失败处理机制。
- **可审计**：记录关键工具调用、审批、外部副作用和最终状态。

## 推荐组合

- **研究型 Agent**：资料研究 Agent + 工具调用 Agent + RAG 检索增强 Agent
- **浏览器自动化**：浏览器执行 Agent + 自动化工作流设计 + Agent 失败恢复
- **企业客服**：客服 Agent + 企业知识库 Agent + 人机审批流程
- **销售自动化**：销售 Agent + 企业知识库 Agent + 自动化工作流设计
- **代码执行**：代码 Agent + 工具调用 Agent + Agent 失败恢复 + Agent 测试与评估
- **长任务**：任务规划 Agent + 长任务执行 Agent + 记忆与上下文管理 Agent
- **外部系统集成**：MCP 与外部工具集成 Agent + 人机审批流程 + Agent 测试与评估
