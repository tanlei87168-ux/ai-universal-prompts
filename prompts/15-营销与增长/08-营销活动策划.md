# 营销活动策划

## 适用场景

设计能落地、能核算、能复盘的线上或线下营销活动。

## 输入变量

- `{{活动目标}}`
- `{{产品}}`
- `{{受众}}`
- `{{时间}}`
- `{{预算}}`
- `{{渠道}}`
- `{{资源}}`
- `{{限制条件}}`

```text
{{业务目标}}

产品 / 服务：
{{产品服务}}

{{目标客户}}

已有数据与材料：
{{已有数据}}

预算与资源：
{{预算资源}}

{{限制条件}}

执行原则：
1. 先明确业务目标、目标客户和真实约束，再设计营销动作。
2. 不虚构用户需求、市场数据、案例、销量、效果、评价或竞争信息。
3. 区分“假设”和“已验证事实”，没有数据的判断必须标记为待验证。
4. 每项营销动作尽量对应一个清晰目标、用户阶段和衡量指标。
5. 优先设计可小规模验证的方案，再决定是否扩大投入。
6. 不使用虚假稀缺、误导性价格、伪造评价、隐藏条件、强迫分享等欺骗性增长手段。
7. 关注获客成本、转化率、毛利、复购、LTV 和执行成本，不只追求曝光或互动。
8. 输出必须能落地执行，包括负责人、步骤、资源、指标或实验条件中的必要项。

请按下面的工作流完成。
```

## 标准工作流

1. 先确定唯一主目标：拉新、成交、留资、复购、到店、传播或会员增长。
2. 明确参与人群、参与门槛、用户获得什么、品牌获得什么。
3. 设计活动机制，并检查规则是否简单到用户一眼能理解。
4. 测算优惠、奖品、渠道、人工和履约成本，避免只看参与量。
5. 设计预热、上线、高潮、收尾和二次转化节奏。
6. 明确页面、物料、客服、销售、库存和技术的协同需求。
7. 避免虚假中奖、诱导分享、隐藏规则和误导性价格。
8. 设置活动指标、异常预案和复盘模板。

## 输出结构

- 活动目标
- 活动机制
- 用户路径
- 时间节奏
- 预算与成本
- 物料清单
- 风险预案
- 指标与复盘

## 质量检查

提交前检查：

- 是否明确了目标客户，而不是面向“所有人”。
- 是否把品牌表达、渠道动作和成交链路连接起来。
- 是否存在无法证明的效果承诺或宣传数据。
- 是否给出可衡量指标和数据口径。
- 是否考虑成本、毛利、团队执行能力和时间。
- 是否把短期促销误当成长期增长。
- 是否有明确的下一步验证动作。
- 是否避免欺骗性、骚扰式或不透明营销方式。

## 使用建议

- 有历史数据时优先提供真实数据；没有数据时，把建议当作实验假设。
- 对广告、渠道和活动，建议先小预算测试，再根据结果增加投入。
- 涉及价格、优惠、宣传效果和用户评价时，必须保持真实、清晰、可核验。
