# 营销与增长 Prompt

共 **18 个正式 Prompt**。这一专区重点解决从定位、获客、内容、广告、转化到留存复购的完整增长链路。

与其他分类的区别：

- **自媒体运营**：更偏平台内容生产与账号运营。
- **销售与客服**：更偏线索跟进、销售成交与客户沟通。
- **商业分析**：更偏市场、商业模式和经营决策。
- **营销与增长**：更偏 **如何找到客户、建立需求、提高转化、促进复购并持续做增长实验**。
